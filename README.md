# 📊 HR Analytics Executive Dashboard

## 📌 Project Overview
An end-to-end HR Analytics solution designed to provide data-driven insights into employee performance, department productivity, and workforce trends using Power BI, SQL, and Excel.

## 🛠️ Tech Stack & Skills
- **Power BI**: Custom "Emerald Dark" UI Theme, Shape Layering, DAX
- **SQL**: Multi-table JOINs, Aggregations
- **Excel**: Data Preprocessing

## 💡 Key Business Insights
- **Top Performing Department**: Department **D07** achieved the highest overall task completion rate.
- **Regional Breakdown**: **Pune** emerged as the primary hub for high-performing talent.
